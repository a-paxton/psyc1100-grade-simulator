# Grade simulator for PSYC 1100 (Fall 2026)

A tiny Shiny app for students to simulate their grade bundles for PSYC 1100
(University of Connecticut), including the opportunity to explore different
performance based on different grades on exam retakes.

For more on our grading system, check out
[our syllabus](https://uconn-my.sharepoint.com/:w:/g/personal/alexandra_paxton_uconn_edu/IQC-q5YBsR-OTpW-PmQY0E5rAVikY2uj4EQz0FvJAMH_1rg).

You can find the deployed app here: https://a-paxton.shinyapps.io/psyc1100-grade-simulator/
